# 🌙 Moons Framework

> **Simple as a script. Fast as a binary.**

O **Moons Framework** é uma solução voltada para execução e desenvolvimento rápido em ambiente isolado. Ele automatiza o setup do seu ambiente de trabalho via Docker, permitindo rodar suas aplicações em um container configurado e pronto para uso com um único comando.

---

## 📋 Pré-requisitos

Antes de iniciar, garanta que sua máquina possui as seguintes ferramentas instaladas:

* [Git](https://git-scm.com/)
* [Docker](https://www.docker.com/)

---
